# AutoCAD 官方下载链接

[English](./README_EN.md)

此索引收录 Autodesk 服务器上的 AutoCAD 主程序安装包，均为 Windows 64 位简体中文版。不收录第三方镜像、激活工具或补丁。安装包下载不等于获得使用许可。

## 安装说明

- 同一版本有两个分卷时，下载全部文件到同一目录，再运行第一部分（文件名含 '001'）。单文件版本直接运行该文件。
- 链接核对到了文件响应，未完整下载或验签。若无法下载，可查阅 [Autodesk Account](https://manage.autodesk.com/products/all) 和[官方安装说明](https://www.autodesk.com/support/technical/article/caas/sfdcarticles/sfdcarticles/How-to-download-a-complete-Autodesk-software-installation-package.html)。
