# AutoCAD Official Download Links

[简体中文](./README.md)

This index links to full AutoCAD installers hosted by Autodesk. All packages below are for 64-bit Windows in Simplified Chinese. Official updates are listed separately from full installers. No third-party mirrors or activation tools are included. Downloading an installer does not grant a license.

## Installation

- For split installers, save both parts in the same directory, then run the first file (the one numbered 001). For a single-file installer, run that file.
- Links were checked for a file response, not fully downloaded or signature-verified. If a link fails, check [Autodesk Account](https://manage.autodesk.com/products/all) and the [official installation guide](https://www.autodesk.com/support/technical/article/caas/sfdcarticles/sfdcarticles/How-to-download-a-complete-Autodesk-software-installation-package.html).

## Update notes

Updates are for the matching Windows x64 release, not standalone installers. File responses were checked; full downloads, signatures, and installation were not tested.

## Contributing download links

Issues and pull requests are welcome. Include the version, language, and all parts, and only link to Autodesk-hosted downloads.
